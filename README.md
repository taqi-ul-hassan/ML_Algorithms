# ML Algorithms

A collection of **Machine Learning algorithms implemented from scratch** using Python.

The goal of this repository is to understand the mathematics, intuition, and implementation behind common machine-learning algorithms rather than relying entirely on high-level libraries.

## Algorithms

| Algorithm                       
| K-Nearest Neighbors (KNN)          
| Linear Regression                  
| Logistic Regression                
| Decision Tree                    
| Random Forest                      
| Naive Bayes                        
| K-Means Clustering                 
| Support Vector Machine (SVM)       
| Principal Component Analysis (PCA) 

## 🎯 Purpose

This repository is part of my journey to build a strong understanding of Machine Learning fundamentals.

For each algorithm, the focus is on:

* Understanding the underlying intuition
* Understanding the mathematics behind the algorithm
* Implementing the algorithm from scratch
* Testing it on datasets
* Comparing implementations with standard ML libraries where applicable
